# Rota 10A — Jogos Fora

- `index.html`: protótipo de aplicação com calendário e página autónoma por jogo.
- `rota10a_jogos_fora_dados_2026-27.json`: dados de jogos e locais.
- `rota10a_jogos_fora_schema.json`: esquema JSON.

A página inicial mostra os jogos. Ao selecionar um, abre uma página completa dividida em paragens na viagem, refeição no destino, comida rápida/cafés e estádio/acessos. O HTML incorpora dados para funcionar offline; no GitHub Pages tenta carregar o JSON externo. Dados de calendário e locais carecem de confirmação editorial antes da publicação.
